# Checklist de Usabilidad - VITTOSTORE

## Navegación
- [ ] El menú principal es visible y accesible desde cualquier pantalla.
- [ ] El usuario siempre sabe en qué sección está.
- [ ] Hay un flujo claro para volver al inicio o dashboard.

## Claridad y consistencia
- [ ] Los botones y enlaces tienen nombres claros y coherentes.
- [ ] Los iconos y colores se usan de forma consistente.
- [ ] Los mensajes de error y éxito son comprensibles.

## Accesibilidad
- [ ] Contraste suficiente entre texto y fondo.
- [ ] Tamaños de fuente legibles.
- [ ] Navegación posible con teclado.
- [ ] Imágenes y botones tienen texto alternativo.

## Feedback y validación
- [ ] El usuario recibe confirmación al realizar acciones importantes.
- [ ] Los formularios validan datos antes de enviar.
- [ ] Se muestran mensajes claros ante errores.

## Dispositivos y rendimiento
- [ ] La app funciona correctamente en móviles y escritorio.
- [ ] Los tiempos de carga son aceptables (<2s).
- [ ] No hay elementos que se desborden o solapen.

---

# Guía para Auditar la Interfaz

1. **Revisa cada pantalla usando la checklist anterior.**
2. **Prueba flujos completos:**
   - Alta y edición de productos
   - Creación de campañas
   - Recuperación de carritos
   - Visualización de reportes
3. **Solicita feedback a usuarios reales y registra problemas encontrados.**
4. **Utiliza herramientas como Lighthouse para evaluar accesibilidad y performance.**
5. **Documenta hallazgos y prioriza mejoras según impacto en el usuario.**
