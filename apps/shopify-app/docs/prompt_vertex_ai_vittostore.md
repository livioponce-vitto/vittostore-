# Prompt para Google Vertex AI Studio: VITTOSTORE

Desarrolla una solución SaaS llamada VITTOSTORE para la gestión avanzada de tiendas Shopify, enfocada en la recuperación de carritos abandonados, automatización de campañas de marketing, monitoreo y personalización de la experiencia del usuario. Utiliza las capacidades de Vertex AI para implementar:

1. Modelos de predicción de abandono de carrito y segmentación de clientes.
2. Recomendaciones personalizadas de productos.
3. Automatización inteligente de campañas y notificaciones multicanal (email, SMS, WhatsApp, push).
4. Dashboards interactivos para visualización de métricas y logs en tiempo real.
5. Integración segura con la API de Shopify y almacenamiento escalable en Firestore o BigQuery.
6. Orquestación de tareas y jobs automáticos usando Cloud Scheduler y Pub/Sub.
7. Cumplimiento de normativas de privacidad y seguridad.

La solución debe ser modular, escalable y fácil de mantener, con documentación técnica y pruebas automatizadas. El frontend debe ser moderno y accesible, permitiendo la gestión de campañas, visualización de métricas y configuración de la tienda.
