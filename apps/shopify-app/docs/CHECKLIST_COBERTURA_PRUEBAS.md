# Checklist de Cobertura de Pruebas

- [ ] Pruebas de acceso sin sesión (401)
- [ ] Pruebas de acceso con sesión/autenticación válida
- [ ] Creación, edición y eliminación de productos
- [ ] Creación, edición y eliminación de campañas
- [ ] Creación, edición y eliminación de órdenes
- [ ] Creación, edición y eliminación de canales
- [ ] Pruebas de errores y validaciones (campos obligatorios, datos inválidos)
- [ ] Pruebas de flujos completos (alta, consulta, baja)
- [ ] Pruebas de sincronización manual y programada
- [ ] Pruebas de seguridad (roles, rutas protegidas)
- [ ] Pruebas de webhooks (todos los eventos relevantes)
- [ ] Pruebas de recuperación de carritos
