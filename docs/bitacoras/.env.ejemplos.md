# Ejemplos de archivos .env

## .env (Desarrollo)
SHOPIFY_API_KEY=dev_api_key
SHOPIFY_API_SECRET=dev_api_secret
DB_HOST=localhost
DB_USER=postgres
DB_PASS=postgres
NODE_ENV=development

## .env (Producción)
SHOPIFY_API_KEY=prod_api_key
SHOPIFY_API_SECRET=prod_api_secret
DB_HOST=localhost
DB_USER=postgres
DB_PASS=postgres
NODE_ENV=production

### Recomendaciones
- Nunca subas tus archivos .env a git.
- Usa valores reales y seguros en producción.
